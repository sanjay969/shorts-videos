# Privacy Policy – ToonSpark Uploader

ToonSpark Uploader is a private tool used only by the owner of the YouTube channel @toonspark96 to upload the channel's own videos.

- It asks for one permission: uploading videos to the owner's own YouTube channel (`youtube.upload`).
- It does not collect, store, sell or share any personal data of anyone else.
- The access token is kept as an encrypted GitHub Actions secret and is used only to upload videos from this repository.
- The owner can revoke access at any time at https://myaccount.google.com/permissions.

Contact: through the GitHub profile https://github.com/sanjay969
